# Sachin Thakor Portfolio

A modern personal portfolio website built with React, Vite, and Tailwind CSS. It showcases my skills, projects, about section, and a working contact form.

## Features

- Responsive design for mobile, tablet, and desktop
- Smooth single-page navigation
- Home, Skills, Projects, About, and Contact sections
- Working contact form using Web3Forms
- Modern UI built with Tailwind CSS

## Tech Stack

- React
- Vite
- Tailwind CSS
- Web3Forms

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
